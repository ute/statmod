Looking at the data

In last Wednesday lecture, we looked at the data set from Problem 7.5, originally exercise 7.30 in Agresti. The data are numbers of shark attacks recorded over 13 years. We discussed if there was a trend, and if the data really can be seen as independent identically distributed Poisson variables

# Agresti, exercise 7.30
attacks <- c(33, 29, 29, 12, 17, 21, 31, 28, 19, 14, 11, 26, 23)
year <- 2001 : 2013
n <- length(attacks)

plot(attacks ~year)

It was claimed that the number of attacks was increasing lately (in 2012, 13). However, there is no really clear trend in the data, and if at all, maybe it is decreasing, with quite some more attacks in 2001/02.

Index of dispersion and testing in a simple i.i.d. sample

Can we explain the data as Poisson random variables with same mean? Then mean and variance should be roughly equal.

mean(attacks)
[1] 22.53846
var(attacks)
[1] 55.76923

The variance is about twice as big as mean, actually 2.5 times the mean. How likely is such a big variance in a Poisson distribution? If we assume that the sample is i.i.d, we can build a simple simulation test on the index of dispersion: the ratio of variance to mean.

D <- var(attacks) / mean(attacks) 

nsim <- 999
Dsim <- numeric(nsim)

for (i in 1:nsim){
  x <- rpois(n, lambda = 22.5)  # n = 13 was the sample size
  Dsim[i] <- var(x) / mean(x)
}

hist(Dsim)
abline(v = D, col = "red") # true value

How would we find a \(p\)-value?

We could apply a simulation test or use the fact that \(D(n-1)\) has in very good approximation a \(\chi^2\) distribution with \((n-1)\) degrees of freedom.

cat("p-values: simulation based p =", (sum(Dsim > D)+1)/(nsim + 1), 
    "asymptotic p =", 1 - pchisq(D*(n-1), df= n-1))
p-values: simulation based p = 0.004 asymptotic p = 0.00310546

Tests of overdispersion for Poisson glm

Likelihood ratio test

More generally, in particular when we deal with glm where the counts depend on explanatory variables, we could test the Poisson distribution against the negative binomial with a likelihood ratio test. This has its own peculiarities, see here.

For the “trivial” model where the counts are i.i.d. and do not depend on explanatory variables, this is done as follows:

fitpois_1 <- glm(attacks ~ 1, family = poisson)
fitnb_1 <- MASS::glm.nb(attacks ~ 1)

G <- -2 * (logLik(fitpois_1) - logLik(fitnb_1))

# a logLik object! tip: attributes
attributes(G)

1cat("Likelhood ratio test p =", (1-pchisq(G, df=1)) / 2 )
1
note the correction for conservativeness: the \(p\)-value is divided by 2. Theoretical background for this was given in this blog entry.

Regression based dispersion test

Cameron and Trivedi (1990) have developed a flexible test for over- and underdispersion, which is implemented in package AER

AER::dispersiontest(fitpois_1, alternative = "greater")

    Overdispersion test

data:  fitpois_1
z = 2.2237, p-value = 0.01308
alternative hypothesis: true dispersion is greater than 1
sample estimates:
dispersion 
  2.284064

This test uses asymptotic normality of its test statistic and is conservative when the sample size is not large. You can also see the conservativeness in this example: the \(p\)-value is larger than in the other tests we performed before.

Linear trend?

We can test for a linear trend in both the Poisson and the negative binomial model by a likelihood ratio test, which is implemented as function anova.

First fit the two models.

Btw, what was the link function in the negative binomial model?

family(fitnb_year)

Family: Negative Binomial(20.1527) 
Link function: log

Aha, MASS::glm.nb uses the log-link by default. This is not the canonical link function, see again the last blog entry

Let us compare the fit obtained in the two models in a plot:

plot(year, attacks)

points(year, predict(fitpois_year, type = "response"), col = 4, type = "b")
points(year, predict(fitnb_year, type = "response"), col = 2, type = "b")

legend('bottomleft',c("fit Poisson", "fit NB"), col = c(4, 2), 
       lty = "solid", pch = 1, bty = "n")

The fitted mean values are almost the same in both models.

For the negative binomial model, the trend is not statistically significant, although it is almost the same as in the Poisson model.

🤔 How can this be? Why is it different when we use the Poisson model?

👉 Bear in mind that the negative binomial model explains a higher proportion of the variance in the data being due to randomness. The anova test for glm retrieves the variance from the mean, using the variance function of the model.

AIC

The negative binomial model without trend wins the race, very closely followed by the NB model with trend.
