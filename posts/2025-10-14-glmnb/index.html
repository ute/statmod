Is the negative binomial model an exponential dispersion family?

Well, it depends.

Let us look at the probability density function. We had introduced the negative binomial distribution as the distribution of a Poisson variable with parameter \(\lambda\) drawn randomly from a Gamma distribution with shape \(k\) and scale \(\mu/k\).

The probability density then takes the form \[ \begin{aligned} f(y; \mu, k) &= \frac{\Gamma(y+k)}{\Gamma(k)\cdot y!} \left(\frac{\mu}{\mu+k}\right)^y\left(\frac{k}{\mu+k}\right)^k \\ &=\exp\left(y \log \left(\frac{\mu}{\mu+k}\right) + k\left(\frac{k}{\mu+k}\right) + \log\left(\frac{\Gamma(y+k)}{\Gamma(k)\cdot y!}\right)\right),\quad \mu>0,\ k>0 \end{aligned} \] When the parameter \(k\) is fixed (known), then \(\{f(.;\mu, k), \mu>0\}\) is an exponential dispersion family, with

  • canonical parameter \(\theta = \log \left(\frac{\mu}{\mu+k}\right)\),
  • cumulant function \(b(\theta) = -k\log(1-\text{e}^\theta)\),
  • dispersion parameter \(\phi = 1\).

However, the full family \(\{f(.;\mu, k), \mu>0, k> 0\}\) is unfortunately not an exponential dispersion family.

It is therefore possible with standard methods to get a maximum likelihood estimate for \(\theta\), and thus for \(\mu\), if we know \(k\), but not necessarily to estimate \(\theta\) and \(k\) simultaneously.

Iterative solution to fit a negative binomial glm with two parameters, \(\mu\) and \(k\)

The most common way to fit a NB glm is iteratively fitting \(\mu\) and \(k\). In the model, \(k\) is assumed to be a constant that does not depend on the explanatory variables. This is also implemented in the glm.nb function from the MASS package.

  • first make an initial guess \(k_0\) for \(k\),
  • then iterate until changes from one iteration to the next are sufficiently small:
    • fit a NB glm with known \(k\) from the previous iteration (or start value), and get the estimate for \(\mu\) from there
    • then solve the maximum likelihood equations for \(k\), using the latest estimate for \(\mu\) like a known constant.

Maximum likelihood fitting one parameter while replacing the others by estimates is called maximum profile likelihood

The canonical link function, \(g(\mu)=\log \left(\frac{\mu}{\mu+k}\right)\), turns out to be problematic with this procedure, because it depends on both \(\mu\) and \(k\), which can add to instability and non-convergence. Therefore, traditionally other link functions are preferred that only depend on \(\mu\).

A recent paper by Miranda-Soberanis and Lee (2023): Two-parameter link functions, with applications to negative binomial, Weibull and quantile regression (Computational Statistics, Vol 38, 1463–1485) sheds more light on the problematics of the canonical link function in the NB model.

Does a maximum likelihood estimate always exist at all?

Negative binomial distributions with fixed parameter \(k\) form an exponential family, thus we can be sure to find a unique maximum likelihood estimate for \(\mu\). However, for the two-parameter family NB(\(k\), \(\mu\)), not all samples yield a maximum likelihood estimate. For the Pascal distributions (where \(k\) is an integer), it has already been conjectured by Anscombe (1950, page 367) that a maximum likelihood estimator exists if and only if the sample mean is smaller than the sample variance (the latter with divisor \(n\), not \(n-1\)). The conditions have been made more precise in later papers. Anscombe suggests to set \(\hat{k}=\infty\) in the cases where the maximum likelihood estimator for \(k\) does not exist, and thus assume a Poisson distribution.

You can read more about that interesting problem in the 2019 paper “On computing maximum likelihood estimates for the negative binomial distribution” by Bandara, Gill and Mitra (Statistics & Probability Letters, 148, 54-58).

R details (package MASS) and experiments

family negative.binomial

The R library MASS includes a family negative.binomial for use with the glm function. In the functions for negative binomial models, the parameter \(k\) is called theta. Maybe you can think of it as written as \(\vartheta\), not to confound it with the canonical parameter.

If family = negative.binomial is used in a call to glm, it will use the log-link function as default, not the canonical link. The canonical link for the negative binomial, \(g(\mu)=\log(\frac{\mu}{\mu+k})\) is is not implemented. Alternatives to the log link are the identity link, and the square root link sqrt.

Likelihood ratio test of the Poisson null hypothesis vs NB

It has been suggested to use a likelihood ratio test of Poisson distribution against negative binomial distribution to check for overdispersion, while correcting for the cases where the maximum likelihood estimate does not exist.

The log likelihood ratio statistic is given as

\[ G_{\text{Pois-NB}}(\boldsymbol{y}) = -2 \left(\ell_{\text{Poisson}}(\hat\mu;\boldsymbol{y}) -\ell_{\text{NegBinom}}(\hat\mu, \hat{k};\boldsymbol{y})\right) \]

In cases where the sample variance is smaller than the sample mean, we get \(G(\boldsymbol{y}) = 0\), or a very small nominal value.

Let \[ D(\boldsymbol{Y}) = \frac {s_n^2(\boldsymbol{Y}) }{\overline{Y}},\quad {\overline{Y}}=\frac{1}{n}\sum_{i=1}^n Y_i,\quad s_n^2(\boldsymbol{Y})= \frac{1}{n}\sum_{i=1}^n (Y_i-\overline{Y})^2. \] Claim 1: if \({\boldsymbol{Y}}\) is an i.i.d. sample from a Poisson distribution, then conditioned on \(D(\boldsymbol{Y}) > 1)\), the statistics \(G_{\text{Pois-NB}}(\boldsymbol{Y})\) is asymptotically \(\chi^2\) distributed with \(df=1\) degrees of freedom, \[ G_{\text{Pois-NB}}(\boldsymbol{Y}\mid D(\boldsymbol{Y}>1)) \mathrel{\dot{\sim}}\chi^2_1. \]

Claim 2: if \({\boldsymbol{Y}}\) is an i.i.d. sample from a Poisson distribution, then \[ P(D(\boldsymbol{Y}) > 1)\xrightarrow[n\to\infty]{} \frac{1}{2}. \]

In the cases where we get no maximum likelihood estimate, we have \(G_{\text{Pois-NB}}(\boldsymbol{Y}\mid D(\boldsymbol{Y}\leq1))=0\), or something close to zero, due to numerical effects, because we would actually fit a Poisson distribution under the NB model. If Claim 2 can be taken to be approximately correct, we would not reject the null hypothesis in 50% of all samples, just because we cannot fit a NB model. In the other 50%, we would obtain a \(\chi^2_1\) distributed statistic, given Claim 1 is applicable. If we bluntly calculate the \(p\)-value as \(p=1-F_{\chi^2_1}(G_{\text{Pois-NB}})\), we would get a very conservative test.

It is therefore suggested to calculate the \(p\)-value as \[ p_{\text{Pois-NB}}(\boldsymbol{y})=\frac{1}{2}\left(1-F_{\chi^2_1}(G_{\text{Pois-NB}}(\boldsymbol{y}))\right) \]
