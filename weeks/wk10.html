Week 10: Numerical Methods and Markov Chain Monte Carlo 1: the Gibbs sampler

Tricking MathJax with invisible \(a^2+b^2\)

Tricking MathJax with invisible \(a^2+b^2\)

We will start with the “Bayesian CLT”, a fast approximation method to find posterior summaries.

Next, we will discuss the general idea of Markov Chain Monte Carlo methods. These methods are based on results for Markov chains – we will shortly review these results. You may know Markov chains with finitely many possible outcomes, that is, the values are integers (finite state space). Here, we use Markov chains with real valued outcomes (continuous state space).

Friday lecture concentrates on the Gibbs sampler, a method that allows to generate random samples from the posterior distribution a multidimensional parameter. In essence it consists in updating one element of the multidimensional parameter at a time.

The other very important MCMC method is the Metropolis-Hastings algorithm. It enables us to simulate from a distribution that is known up to a constant. If time allows, we will start with the Metropolis algorithm in the end of Friday’s lecture.

In order to understand the algorithms, you will implement them yourselves in R. Later in this course you will use software “off the shelf” to run MCMC. You will learn to use JAGS and the R package rjags to analyze simple Bayesian models.

Problem 10.1: MAP and numerical integration

Reich & Ghosh, Chapter 3, Exercise 2

Assume that \(Y\mid\mu \stackrel{\text{indep.}}{\sim} \mathrm{Normal}(\mu,\sigma_i^2)\), for \(i = 1,\dots, n\), with \(\sigma_i\) known and improper prior distribution \(\pi(\mu) = 1\) for all \(\mu\).

  1. Give a formula for the MAP estimator for \(\mu\).

  2. We observe \(n = 3, Y_1 = 12, Y_2 = 10, Y_3 = 22\), and know that \(\sigma_1 = \sigma_2 = 3\) and \(\sigma_3 = 10\). Compute the MAP estimate of \(\mu\).

  3. Use numerical integration to compute the posterior mean of \(\mu\).

  4. Plot the posterior distribution of \(\mu\) and indicate the MAP and the posterior mean estimates on the plot.

Hints

Parts a) and b) can be solved without R; you might want to compare your analytical result for the MAPin b) with numerical results by R function optim.

For parts c) and d), find ideas in listing 3.1, R&G page 72. You can use function adaptIntegrate from package cubature, or just work with base R function integrate here. You can download the R code here.

Both functions calculate the integral of a function that can take a vector of all arguments and would return a vector of all function values. If your own function only returns a single number, you will get weird results. The remedy is then to create a new version of your function by applying R function Vectorize.

  4. Use the Bayesian CLT to approximate the posterior of \(\lambda\) under the setting of (c), plot the approximate posterior, and compare the plot with the plot from (c).

Problem 10.3: Inference for the variance in a hierarchical normal model

Reich & Ghosh, Chapter 3, Exercise 4 (a) – (d).

Consider the model \(Y_i\mid\sigma^2_i\stackrel{\text{indep}}{\sim}\mathrm{Normal}(0,\sigma^2_i)\) for \(i=1\dots n\), where \(\sigma^2_i\mid b\sim\mathrm{InvGamma}(a, b)\) and \(b\sim\mathrm{Gamma}(1,1)\).

  4. Repeat the analysis with \(a = 1\) and comment on the convergence of the MCMC chain.

Problem 10.4: Gibbs sampling for comparison of two groups in normal model

Reich & Ghosh, Chapter 3, Exercise 5 (a) – (c).

Consider the model \(Y_i\mid\mu.\sigma^2\sim \mathrm{Normal}(\mu,\sigma^2)\) for \(i = 1,\dots, n\) and \(Y_i\mid\mu,\sigma^2\sim \mathrm{Normal}(\mu+\delta,\sigma^2)\) for \(i = m+1,\dots, n+m\), where \(\mu,\delta \sim \mathrm{Normal}(0,100^2)\) and \(\sigma^2\sim\mathrm{InvGamma}(0.01,0.01)\).

  1. Give an example of a real experiment for which this would be an appropriate model.

  2. Derive the full conditional posterior distributions for \(\mu\), \(\delta\), and \(\sigma^2\).

  3. Simulate a dataset from this model with \(n = m = 50\), \(\mu = 10, \delta = 14\), and \(\sigma = 2\). Write your own Gibbs sampling code (not in JAGS) to fit the model above to the simulated data and plot the marginal posterior density for each parameter. Are you able to recover the true values reasonably well? Try to find out if your result in (c) varies a lot when you simulate again.

Problem 10.5: Interesting and relevant properties of the AR(1) process

In the lectures, we discuss(ed) the autoregressive process AR(1) as an example for a Markov chain (see the interactive experiment)

Consider the AR(1) chain \(X_0, X_1, \dots\) given by \[ X_{n} = \phi X_{n-1} + \lambda + \tau Z_n, \quad n=1, 2, \dots,%\quad Z_1,Z_2,\dots\iidsim \Nor(0, 1), \ \phi\in(-1,1), \ %\lambda\in\R,\ \tau>0 \] where \[ %X_{n} = \phi X_{n-1} + \lambda + \tau Z_n, \quad n=1, 2, \dots,\quad Z_1,Z_2,\dots\stackrel{\text{i.i.d.}}{\sim }\mathrm{N}(0, 1), \ -1<\phi<1, \ \lambda\in\mathbb{R},\ \tau>0, \] and \(Z_n\) is independent of \(X_m\) for all \(n\) and \(m<n\).

  1. Give an argument that the \(X_n\) in such a chain must have a normal distribution. Thus, the stationary distribution must be a normal distribution.

    Show that the normal distribution with mean \(\mu = \lambda/(1-\phi)\) and variance \(\sigma^2=\tau^2/(1-\phi^2)\) is the stationary distribution of the chain.

    Run some simulation(s) to confirm this result.

  2. Confirm by calculation or simulation, that, for all \(n\in\mathbb{N}\) and \({k=0,1,\dots,n-1}\) \[ \mathrm{Cov}(X_n, X_{n-k}) = \phi^k \sigma^2, \quad\text{or, equivalently,\quad} \mathrm{Cor}(X_n, X_{n-k})=\phi^k. \]

  3. Investigate the variance of the sample mean \[ \overline{X}_{(m)}=\frac{1}{m}\sum_{i=1}^m X_i \]
    from values \(X_1,\dots, X_m\) from the AR(1) chain started in a random value \(X_0\) from the stationary distribution, and compare with the variance that you would get when the samples \(X_1,\dots,X_m\) were drawn independently from the stationary distribution.

    Do this by simulating for several values of \(\phi\), also for some negative ones. What can you conclude?
