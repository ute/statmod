Week 6: Algorithms, and models for count data

Tricking MathJax with invisible \(a^2+b^2\)

We will conclude the general topics about mle for now with a look at the actual algorithms behind maximum likelihood estimation as done by function glm: Fisher scoring and iteratively reweighted least squares.

Then we continue with particular generalized linear models, for binary and count data. For binary or binomial data (proportions of successes in Bernoulli trials), numerous link functions have been suggested. They can be motivated by a “model hidden behind the model”: we imagine that the success of a Bernoulli trial depends on an unknown “latent” variable. An important application for the binomial model are contingency tables. The straightforward choice for count data are Poisson distributions. We will see that the canonical link function (log link) has a direct interpretation as “multiplicative” model.

If there is time, we will look at the theory behind the AIC criterion for model fit.

Relevant Readings

  • Algorithms to find the mle: Agresti, 4.5, Davison 10.2.2 and 10.3.2.
  • Models for binary and count data: Davison, 10.4, 10.5.
  • Multinomial model and the “Poisson trick”: Davison 10.5.2.

Problem 6.2: Model parsimonity: a simulation experiment.

(Adapted from Agresti (2015), exercises 4.36 and 4.37)

For \(x\) between 0 and 100, suppose the normal linear model holds with \[\mathrm{E}\,(y) = 45 + 0.1x + 5\cdot 10^{-4}\, x^2 + 5\cdot 10^{-7}\, x^3 + 5\cdot 10^{-10}\,x^4 +5\cdot 10^{-13} \,x^5\]

and \(\sigma = 10.0\). Randomly generate \(n=25\) observations from the model, with \(x\) having a uniform distribution between 0 and 100. Fit the simple model \[ M_1:\quad \mu_j= \beta_0 + \beta_1x_j, \] an “intermediate” model \[ M_2:\quad \mathrm{E}\,(y) = \beta_0+\beta_1 x + \beta_2 x^2, \] and the “correct” model \[ M_5:\quad \mathrm{E}\,(y) = \beta_0 + \beta_1 x + \cdots + \beta_5x^5. \]

Construct plots, showing the data, the true relationship, and the model fits. For each model, summarize the quality of the fit by the average of \(|\hat\mu_j - \mu_j|\), that is, \(\frac{1}{n}\sum_{j=1}^n |\hat\mu_j - \mu_j|\), where \(\mu_j=\mathrm{E}\,(y_j)\) and \(\hat\mu_j\) is the \(j\)th fitted value, depending on the model: for example in model \(M_1\), \(\mu_j=\beta_0+\beta_1 x_j\) and \(\hat\mu_j=\hat\beta_0+\hat\beta_1 x_j\).

Repeat the experiment several times with different \(x\)-values. It is also interesting to look what happens if you increase the number of observations substantially, or change the true coefficients.

Summarize, and explain what this exercise illustrates about model parsimony. What does the fit of the “correct” model \(M_5\) illustrate about (multi)collinearity?

Hint

To fit polynomial models such as \(M_2\) in R, you can directly specify the components: y ~ I(x) + I(x^2) or use the convenient function poly, namely y ~ poly(x, 2, raw = TRUE).

Problem 6.3: A graphical model check.

(From Agresti, 7.28)

Other than a formal goodness-of-fit test, one analysis that provides a sense of whether a particular GLM is plausible is the following:

Suppose the ML fitted equation were the true equation. At the observed \(x\)-values for the \(n\) observations, randomly generate \(n\) variates with distributions specified by the fitted GLM. Construct scatterplots. Do they look like the scatterplots that were actually observed?

Do this for a Poisson loglinear model for the horseshoe crab data1, with \(y\) = number of satellites and \(x\) = width. Does the variability about the fit resemble that in the actual data, including a similar number of 0’s and large values? Repeat this a few times to get a better sense of how the scatterplot observed differs from what you would observe if the Poisson GLM truly held.

Problem 6.4: Modelling variance in repeated experiments.

Davison, Problem 10.10.8, plus hints.

  1. Show that the scaled chi-squared density with known degrees of freedom \(\nu\), \[ f(y;\sigma, \nu)=\frac{y^{\nu/2-1}}{2^{\nu/2}\sigma^\nu\Gamma(\nu/2)}\exp\left(-\frac{y}{2\sigma^2}\right),\quad y>0, \sigma>0,\nu=1,2,\dots, \] is exponential dispersion family. Express the canonical parameter \(\theta\) and the dispersion parameter \(\phi\) as functions of \(\nu\) and \(\sigma^2\).
    Hence derive an expression for its \(r\) th cumulant, \(r\geq 1\).

    Hint

    • Consider \(\nu\) as a known constant. Several choices for \(\theta\) and \(\phi\) are possible, and \(\phi\) is a constant, too. One possible choice is \(\phi = -2\); with this choice, the canonical link function depends on \(\nu\). Another option is \(\phi = -2/\nu\) — check it out :-) If you need a reminder for the moment generating function look at the top of Davison, page 481. Then you easily recall the cumulant generating function.

    • To control your calculations: the second cumulant is \(\kappa_2=2\nu\sigma^4\), the variance of \(y\).

  2. The yield of an industrial process was measured \(r_i\) times independently at m different temperatures \(t_i\) . The resulting yields \(Z_{ij} , i = 1,\dots ,m, j = 1, \dots , r_i\) may be assumed to be independent and normally distributed with both \(\zeta_i\) and variances \(\tau_i\) dependent on \(t_i\).

    Explain how the sums of squares \(Y_i =\sum_{j=1}^{r_i}(Z_{ij}-\overline{Z}_i)^2\), where \(\overline{Z}_i=\frac{1}{r_i}\sum_{j=1}^ {r_i} Z_{ij},\) may be used to assess the dependence of variance on temperature in a suitable generalized linear model.

    Briefly discuss the advantages and disadvantages of the canonical link function of your model.

Problem 6.5: Deviance for the binary logistic model.

Davison, Exercises 10.4.1.

This exercise deals with data \(y_1,\dots,y_n\) that come frome independent Bernoulli experiments with probability parameter \(\pi_1,\dots, \pi_n\).

A little extra before solving parts a-c: identify the distribution of \(Y_j\) with \(\mathrm{P}(Y_j=1) = \pi_j\) and \(\mathrm{P}(Y_j=0) = 1-\pi_j\) as an exponential dispersion distribution with dispersion parameter \(\phi=1\). Determine the canonical parameter \(\theta\) and the function \(b\).

Here is the exercise text from Davison:

Data \(y_1,\dots, y_n\) are assumed to follow a binary logistic model in which \(y_j\) takes value 1 with probability \(\pi_j = \exp(x^{\mathsf{T}}_j\beta)/(1 + \exp(x^{\mathsf{T}}_j\beta))\) and value 0 otherwise, for \(j = 1, \dots , n\).

  1. Show that the deviance for a model with fitted probabilities \(\hat{\pi}_j\) can be written as \[ D = −2\left(y^{\mathsf{T}}X\hat \beta +\sum_{j=1}^n \log(1-\hat\pi_j)\right) \] and that the likelihood equation is \(X^{\mathsf{T}}y = X^{\mathsf{T}}\hat\pi\). Hence show that the deviance is a function of the \(\hat\pi_j\) alone.

  2. If \(\pi_1=\dots=\pi_n = \pi\), then show that \(\hat\pi=\bar{y}\), and verify that \[ D = -2n \left(\bar{y} \log \bar{y} + (1-\bar{y}) \log(1 - \bar{y})\right). \] Comment on the implications for using \(D\) to measure the discrepancy between the data and fitted model.

  3. Assuming that \(\pi_1=\dots=\pi_n = \pi\) (as in part (b)), show that Pearson’s statistic, formula (10.21) in Davison, \[ P = \frac{1}{\phi}\sum_{j=1}^n\frac{(y_j-\hat\mu_j)^2}{V(\hat\mu_j)/a_j}, \]
    is identically equal to \(n\). Comment.

Hints

for (a), observe that the likelihood of the saturated model is \(L(\pi)=1\) (this is also the likelhood for the parameter \(\beta\) of the glm).

In (c): Rmember the definition of \(a_j\) in this context: \(a_j=\phi_j/\phi\). In this exercise, use \(\phi=1\) and \(a_j=1\) in formula (10.21).
